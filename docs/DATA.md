# Dataset information

The benchmark uses real-world measurements from the public POWDER wireless
research platform.

Original dataset:

Outdoor 5G Mobility Dataset: Uplink SRS, UE-Side Measurements,
gNodeB Logs/Measurements and Application-Layer Traffic on POWDER

Zenodo:
https://zenodo.org/records/23741918

The repository does not redistribute the original large measurement files.

The benchmark target is:

RSRP (NR SpCell)

Two physical mobility runs are used:

- Run1: 1378 RSRP samples
- Run2: 943 RSRP samples

Total: 2321 physical RSRP samples.

Derived trajectories included in this repository contain only the information
required to reproduce the benchmark geometry and evaluation protocol.
